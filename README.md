# 🏠 Housing Price Prediction

## Project Overview
A Machine Learning project that predicts housing prices using different regression algorithms.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Models Implemented
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## Project Workflow
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training and Evaluation
- Feature Importance Analysis
- House Price Prediction

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Results
Gradient Boosting achieved the highest R² score (0.6661) in the current notebook evaluation.
